# ACORD 125 — form field inventory
#
# Read off the agency's own uploaded template with Settings → Inspect fields
# (crm/src/lib/acordPdf.ts `listTemplateFields`). This is a snapshot, not a
# standard: a different ACORD edition will differ, and the only authority is
# whatever PDF is sitting in S3 for this agency right now.
#
# It is checked in because the alternative is asking a human to re-inspect the
# template every time a workstream needs a field name — which is what left
# `annualRevenue` unmapped through W2 and put six guessed prefixes into W3's
# prior-coverage table, four of which were wrong.
#
# Three things in here that contradicted assumptions the code had made:
#
#   1. Prior coverage is a THREE-YEAR GRID (PolicyYear_A/B/C), and within each
#      year there are only four rows: GeneralLiability, Automobile, Property,
#      and one OtherLine. There is no per-line row for crime, umbrella, D&O,
#      flood, earthquake or workers comp — they share the OtherLine row, whose
#      LineOfBusinessCode field exists on block _A only.
#   2. The line-of-business checkboxes have no WorkersCompensation, Flood,
#      Earthquake or ManagementLiability/DirectorsAndOfficers box. Those lines
#      belong in the six Other rows (_A.._F), each with its own description
#      and premium.
#   3. Annual revenue is per premises (CommercialStructure_AnnualRevenueAmount_
#      A..D), not a single business-level field.
#
# Format: one field per line, as `listTemplateFields` returns it.
